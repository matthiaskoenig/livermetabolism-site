# Release notes for livermetabolism-site 0.8.0

We are pleased to release the next version of the König Lab website, https://livermetabolism.com. This release adds a network page: an interactive graph that connects the five research areas with the people, publications, projects, and software of the lab, and leads from every node to the item on the site.

## Features
- a new "Network" page (`/network/`, in the navbar and linked from every research-area section of the homepage) draws the lab as a force-directed graph: the five research areas as ringed hubs on a pentagon, people with their photos, projects and software with their thumbnails, and publications as dots coloured by research area and sized by citation count; links follow authorship, project and software membership, and topic
- hovering a node shows its name and a detail line (role, year and journal, project title, tool name, or research-area description); clicking a person, paper, project, or tool opens it where it lives on the site (team modal, publication row, project modal, software card), and the browser's back button returns to the graph
- a research-area button, a hub click, or a `?topic=<area>` link focuses that area: its items and their direct neighbours stay visible while the rest is dimmed, without re-arranging the graph; the legend toggles node types; drag to pan, buttons zoom and reset the view

## Performance
- the graph page carries its rows in the page (34 KB gzipped) and loads the graph renderer together with the chart bundle the site already ships; node images are 96 px thumbnails generated once (102 files, 484 KB in total) and served as static assets
- focusing a topic or resizing the window keeps the node positions instead of restarting the layout, so the page stays calm on phones where the address bar changes the viewport height while scrolling

## Fixes
- the `Network` button on the homepage sections and the `active` state of the navbar entry follow the existing patterns; the wheel over the graph scrolls the page instead of zooming it

## Development
- `scripts/graph-thumbs.ts` (`npm run graph:thumbs`) writes the circular people and research-area thumbnails (with a ring in the area's colour) and the square project and software thumbnails into `public/assets/image/graph/` with `sharp`; the output is committed and regenerated by hand when images change
- `site/lib/graphRows.ts` derives the nodes and links from the YAML data and the citation snapshot at build time (pure, tested against the real data: 213 nodes, 507 links); `site/lib/networkOptions.ts` builds the ECharts graph option (pinned hubs, dimming, richText tooltips) without touching the DOM; `GraphChart` joins the registered ECharts components
- Vitest runs 357 tests (46 new), Playwright 33 (the network page renders the canvas and the research-area buttons, `?topic=` focuses, zero console errors on every page)
- the design spec and the plan are in `docs/superpowers/`; `CLAUDE.md` documents the graph rows, the thumbnails, and the island
