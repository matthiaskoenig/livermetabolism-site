# Release notes for livermetabolism-site 0.10.0

We are pleased to release the next version of the König Lab website, https://livermetabolism.com. This release makes the site easier to find and read for search engines and AI agents: a `robots.txt`, and an `llms.txt` and `llms-full.txt` that present the group and all of its content as Markdown, all generated from the site's data on every build.

## Features
- `/robots.txt` welcomes every crawler, AI crawlers and agents included, and points them to the sitemap and the two LLM files; only `/detail/`, the fragments the detail dialogs load, is kept out, as it already is from the sitemap
- `/llms.txt` follows the [llms.txt](https://llmstxt.org/) proposal: a title and short summary of the group, then links to the five research areas, the pages of the site, every software package with its source repository, and the current projects, with the full-content file, the search index, the sitemap, the CV, and the legal pages as optional links
- `/llms-full.txt` holds the whole site as one Markdown file (about 320 KB): the research areas with their vision statements, the team, every publication with authors, DOI, and abstract, the projects, software, funding, editorial roles, presentations, posters, conference abstracts, meetings, teaching, and news, each entry with its link on the site. It shows what the site shows: current projects, current members, and alumni with a photo
- every link in the three files is absolute and follows the deploy's address, so the files stay correct on the interim GitHub Pages URL and on the custom domain

## Development
- `site/lib/llms.ts` builds the three files as pure functions (`robotsTxt`, `llmsTxt`, `llmsFullTxt`) behind the endpoints `site/pages/robots.txt.ts`, `llms.txt.ts`, and `llms-full.txt.ts`; `plainText()` turns the HTML of data fields into plain text with Markdown links and drops affiliation superscripts
- the list of static pages moved from `search.json.ts` to `site/lib/sitePages.ts`, shared by the search index and `llms.txt`; the search index is unchanged
- Vitest runs 431 tests (30 new, including the real data); Playwright runs 44 (the three files are served as text, and every site link in the LLM files resolves)
- the science-communication documents describe the current state of the site; `CLAUDE.md` documents the new files and where a new table must be added
