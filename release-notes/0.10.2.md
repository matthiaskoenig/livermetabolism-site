# Release notes for livermetabolism-site 0.10.2

A patch release of the König Lab website, https://livermetabolism.com, improving consent handling, snapshot link validation, keyboard navigation, mobile layout, and HTTPS redirects.

## Security and privacy

- Withdrawing Analytics consent now disables the running Google tag and removes Analytics cookies on the current hostname and its parent domains. Accepting again reuses the existing tag instead of loading another copy.
- Analytics commands use Google's documented command-queue format.
- Navigable URLs in GitHub and Scholar snapshots must be absolute HTTP(S) URLs. Malformed snapshots retain the site's fallback content; GitHub's free-form homepage metadata remains compatible.
- The German privacy page describes Google Fonts, GitHub snapshot requests, YouTube previews and players, and their independence from Analytics consent. It also documents local consent storage and updates the Analytics IP-handling description and TDDDG reference.

## Fixes

- Pressing Enter on a link inside a project card follows the link instead of opening the parent card's detail dialog.
- The mobile consent banner sizes to its text and buttons instead of reserving 320 pixels for its paragraph.
- Both nginx HTTP configurations redirect deep paths and query strings to HTTPS while continuing to serve ACME certificate challenges. The host configuration explicitly includes the canonical livermetabolism.com hostname.

## Development

- GitHub, Scholar, and citation browser snapshots share fetch, validation, caching, and freshness logic, with a ten-second request timeout and independent caches.
- Added browser regressions for consent withdrawal, parent-domain cookies, nested keyboard links, unsafe snapshot URLs, and the mobile banner.
- Added a repeatable nginx integration check: `python3 scripts/check-nginx-redirects.py` exercises 120 HTTP requests against isolated containers using temporary certificates.
- Repository agent instructions now live in `AGENTS.md`, with `CLAUDE.md` linking to the same instructions.
- Recorded the code/security review and the npm audit result: zero known dependency vulnerabilities at the time of the audit.
- Vitest covers 448 tests, Python validation 36 tests, and Playwright 50 browser tests.
