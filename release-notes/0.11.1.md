# Release notes for livermetabolism-site 0.11.1

A patch release fixing the alignment of the landing-page icons and closing three follow-ups from the internationalization work.

## Fixes
- the icons on the landing page are centred with their headings again (#65). The `.fa` class lands on the SVG itself, which was `display: block` with an explicit width, so the parent's `text-align: center` could not move it and the icon sat at the left edge while the heading centred. This affected the five research-area tiles, the five quick links, and the five research-area sections further down the page, in both languages. The icons are now `inline-block`, so they follow whatever alignment their container uses - centred where the heading is centred, and still left-aligned in the two-column research-area sections on wide screens, where the heading is left-aligned too
- the German privacy notice now uses German typographic quotation marks around "Google" rather than straight ASCII quotes

## Development
- `data/activities.yml` is no longer part of the translatable set, and `i18n/de/activities.yml` has been removed. Activities have never been rendered on the site - the table feeds the Typst CV tooling only - so translating it added a maintenance cost with no visible benefit: editing the English turned CI red for content no visitor can see
- `npm run i18n:check` now covers the legal page catalogs (`i18n/{de,en}/pages/*.yml`) alongside the data tables and the UI catalog. These pages invert the usual direction, since German is the binding source and the English rendering is generated from it, so the generated English entries carry the hash of their German source. Previously the checker could report everything in sync while an edit to the German Impressum left the English silently stale
