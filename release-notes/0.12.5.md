# Release notes for livermetabolism-site 0.12.5

A patch release that adds a software package, gives two software cards their logos, and removes a Content-Security-Policy violation from the research and publications pages.

## News
- `sbmlode` joins the software packages and the GitHub statistics (#99). It derives the system of ordinary differential equations of an SBML model and writes it as simulation code for Python, Julia and R, verified against libRoadRunner over the SBML test suite, or as Typst, LaTeX and Markdown documents of the equations
- the sbml2cellml and sbmlode cards on the research page show the new logos of both packages (#99)

## Fixes
- the research and publications pages no longer report a Content-Security-Policy violation on every load, in either language (#99). Zod probed for `eval` when the first snapshot schema was built and the site's CSP blocked it; the snapshot schemas now run zod `jitless`, which skips the probe. The page tests fail on any CSP violation from now on, which the console-error check could not see

## Development
- dependency updates: devalue 5.9.4 and brace-expansion 5.0.12 (#96, #97)
- Vitest runs 700 tests, Python validation 38 tests, and Playwright 85 browser tests
