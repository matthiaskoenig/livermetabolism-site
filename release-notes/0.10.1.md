# Release notes for livermetabolism-site 0.10.1

A patch release of the König Lab website, https://livermetabolism.com: `pkpdutils`, the refactored successor of `pkdb_analysis`, joins the software packages and the GitHub statistics, and TypeScript moves to version 6.

## Features
- `pkpdutils` (https://github.com/matthiaskoenig/pkpdutils) is listed among the software packages on the research page, right after PK-DB. The Python library for the pharmacokinetic and pharmacodynamic analysis of timecourses and parameters was formerly `pkdb_analysis`, the analysis toolbox of PK-DB; its entry links the documentation, the repository, the Zenodo DOI, Jan Grzegorzewski and Matthias König, and the PK-DB paper (#59)
- from the next GitHub snapshot on, its card and detail show stars, latest release, open issues, and last push, and its releases, weekly commits, and stars enter the release feed, the release history, the commit activity and stars charts, and the homepage total; it also appears in the network graph, the site search, `llms.txt`, and `llms-full.txt`
- the commit activity chart keeps every colour for one repository: with more than ten active repositories, the nine most active keep their own colour and the rest are stacked as one grey "N others" series, whose tooltip lists each of them with its commits that week. Adding `pkpdutils` would otherwise have given PK-DB the colour of livermetabolism.com

## Fixes
- software logos in the detail dialog and in the related rows of a person are shown whole instead of cropped to the thumbnail (the PK-DB, sbmlutils, libsbgnpy, and libRoadRunner logos lost their outer parts)
- the underline of a release link on a software card no longer runs on under the separator after it
- a detail opened from a link, or a related row opened with the keyboard, no longer draws a focus ring around the dialog title

## Development
- TypeScript 6.0.3 (from 5.9.3, #24); `astro check` and `vue-tsc` report no errors
- the detail model has a third image shape, `logo`, for software entries (`.detail-image-logo`, `.related-row-image-logo`)
- Vitest runs 434 tests (3 new), Playwright 45 (1 new, 2 extended); the counts over the real data follow the new entry (13 repositories, 209 network nodes, 309 links)
