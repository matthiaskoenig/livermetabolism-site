# Release notes for livermetabolism-site 0.12.9

A security patch release that updates Astro and the site's dependency stacks (#133).

## Security

- Upgrade Astro from 7.4.4 to 7.4.13, addressing dynamic-tag attribute injection (GHSA-mh32-jxcr-mh9f) and image-endpoint path validation (GHSA-r3h5-4585-7x3w), resolving both open Dependabot alerts.
- Update the nginx container to 1.31.10-alpine and the Node 24 build and development containers to 24.22.3-alpine.
- npm and Python dependency audits report no known vulnerabilities.

## Dependencies and maintenance

- Refresh all compatible npm and Python dependencies and both lockfiles, including Astro's integrations, Vue, Tailwind CSS, Playwright, Vitest, pandas, Pydantic and Typst.
- Align the declared Node minimum with Astro's requirement: 22.23.4.
- Keep TypeScript at 6.0.3 because the current Astro checker does not support TypeScript 7.
- Update setup-uv to 10.4.0 and add Docker Compose images to monthly Dependabot updates.

## Validation

- Astro and Vue type checks, translation catalogs, and data validation pass.
- Vitest runs 727 tests, Python validation 38 tests, and Playwright 85 browser tests for each deployment base path.
- The production build passes in the updated Node Alpine container, the GitHub Pages build passes under its base path, and the updated nginx image accepts the existing configuration.
