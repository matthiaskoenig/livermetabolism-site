# Release notes for livermetabolism-site 0.12.0

We are pleased to release the next version of the König Lab website, https://livermetabolism.com. This release replaces the site's six separate tag filters with a single research-area filter that follows you from page to page.

## Features
- one research-area filter for the whole site, in a bar that stays under the navigation as you scroll. Choose Digital Twins, AI, Digital Pathology, Pharmacometrics or Open & FAIR once and every page you visit shows that area until you clear it - publications, projects, news, software, funding, editors, meetings, the team, teaching, the abstracts, and the network graph
- the chosen area is shown in its own colour as a rule under the bar, so it is clear at a glance that a page is filtered, wherever you have scrolled to
- the network graph uses that same filter now, instead of its own separate set of buttons; its toolbar keeps only the zoom and reset controls
- a section that an area empties keeps its heading and its link target, and says that there is nothing in that area yet, rather than disappearing
- the team page and the teaching page can now be filtered by research area too. A person's areas are taken from the areas of the papers they have co-authored
- abstracts carry research areas as well, so the filter reaches every list on the publications page
- the address bar always shows the area in effect, so a link you copy and share shows the reader what you were looking at. Existing links into a filtered page keep working
- following a search result or a "show in list" link to an entry outside the current area clears the filter and takes you to the entry, rather than to a page where it is hidden
- Pharmacometrics has its own darker green. It previously used the same colour as the site's links, headings and logo, so a Pharmacometrics badge was hard to tell from a link

## Fixes
- there is a "Report an issue" link in the footer (#67), which opens a new issue for the website on GitHub. There is no contact form on the site, so a broken link or a wrong figure had nowhere to be reported
- the three filters on the research page no longer disagree with each other. Choosing an area above the software list left the funding and editors lists unfiltered (#68)

## Development
- the filter is one shared module (`site/lib/topicFilter.ts`) holding a single value, read and written by the bar, the DOM sweep and the chart islands alike. It replaces five `TagFilter` islands keyed by tag name and a sixth, hand-rolled one inside the network graph keyed by slug and reading a different query parameter
- the bar is site chrome rather than a Vue island, so `/news/`, `/projects/` and `/meetings/` now ship no Vue runtime at all
- `position: sticky` did not work anywhere on the site: `body { overflow-x: hidden }` forces `overflow-y: auto`, which makes the body a scroll container and changes what sticky measures against. It uses `overflow-x: clip` now, which suppresses the same horizontal overflow without creating one
- the research-area colours are defined twice by necessity, as CSS custom properties and as a TypeScript map a canvas can read. A test now parses the stylesheet and checks the two against each other, and that no area reuses the site's accent colour
- Vitest runs 650 tests, Python validation 38 tests, and Playwright 78 browser tests
