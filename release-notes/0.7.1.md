# Release notes for livermetabolism-site 0.7.1

Patch release of the König Lab website, https://livermetabolism.com: the citations-over-time chart on the publications page now starts in 2011 instead of on the day the daily snapshots began.

## Features
- the citations-over-time chart shows year-end totals accumulated from Google Scholar's per-year histogram (2011 to the last completed year) ahead of the daily readings, which continue the line from 12 September 2026; the citations the histogram does not date are carried as a constant baseline so the curve meets today's total. Year-end totals are drawn as hollow points, daily readings as filled ones, on a time axis; the caption states both sources

## Development
- `historyRows()` derives the yearly points at build time and in the browser from the same pure helper, so the pipeline and the snapshot are unchanged; unit tests cover the accumulation, the baseline, the hand-over to the daily readings, and the time-axis option
