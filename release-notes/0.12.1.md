# Release notes for livermetabolism-site 0.12.1

A patch release tidying the navigation bar and the research-area filter introduced in 0.12.0.

## Fixes
- the EN/DE language switch sits at the right-hand end of the navigation now, rather than between the logo and the search icon, and is drawn as one bordered switch so it no longer reads as two more menu entries. Each language carries its flag beside the code on wide screens; the flag is dropped where the bar is tight, since it is decorative and the code is what has to stay legible
- the research-area filter row is shorter, sits on a light grey band so it reads as part of the site chrome rather than as the top of the page, and its buttons have square corners
- the research-area badges on cards, the Year / Most cited buttons, the chart mode buttons and the citation counts share those square corners, so every small control on the site has one shape
- every page now starts the same distance below the chrome. Pages without the filter row - the CV, the legal notice and the privacy policy - previously had their first line flush against the navigation, since headings reset their own top margin

## Development
- the language switch and the filter row are covered by browser tests that assert position, height, background, corner radius and the gap to the page content, so this styling cannot drift back unnoticed
- the flags and the right-alignment are both gated on viewport width, and a test measures the navigation bar's height across widths: either one applied too early wrapped the bar onto an extra row, and every page pays that height as body padding
