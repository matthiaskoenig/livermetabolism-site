# Release notes for livermetabolism-site 0.12.7

A patch release that announces the certificate in science communication from TU Berlin, shows every detail image of a news item, and keeps the last verified GitHub, Google Scholar and OpenAlex figures on the site when a daily data source answers empty or implausibly.

## News
- news: Matthias König completed the certificate program Science Communication for (Junior) Scholars of the ZEWK at TU Berlin, whose practical project was the redesign of this website with agentic, AI-assisted workflows, in English and German (#110)
- a news item carries a list of `images` instead of a single `image2`, and the detail modal shows each of them whole at the modal's width; this also brings back the COMBINE 2022 participants photo, which was validated but rendered nowhere (#110)

## Live data
- a daily data source that answers well-formed but empty or truncated no longer replaces the last good snapshot (#111): each fetch compares its headline figures with the previous snapshot (GitHub stars and releases; Scholar citations, h-index and i10-index; OpenAlex DOIs found and their citations) and writes nothing when one fell by more than 10 %, so the pages keep the last verified figures with their "updated ..." date. A real drop is accepted by running the data workflow by hand with `accept_drop`
- a repository whose commit statistics GitHub is still computing keeps its previous weeks in the commit activity chart instead of dropping out of it (#111)
- the daily data workflow fails visibly when a fetch fails, instead of passing silently, and one failing source no longer holds back the other two; a routine Google Scholar block is reported as a warning (#111)

## Development
- the CV sources were updated (#109)
- Vitest runs 725 tests, Python validation 38 tests, and Playwright 85 browser tests
