# Kommunikationskonzept Matthias König

- Ein kurzes Kommunikationskonzept: Dazu hat der verpflichtende Auftaktkurs die Grundlagen gelegt. Es geht darum, kurz zu überlegen: Welche Zielgruppe soll erreicht werden? Mit welchen Zielen? Welche Maßnahmen plant man deswegen und warum? Das kann sehr kurz gefasst sein, auf 1-2 Seiten reicht das.
- Eine neue Webseite oder Science Blog anlegen. Wer ist Ihre Zielgruppe? Wie schreibst du webfreundliche Texte? Welche Formate, welche Bilder, welche Inhalte wählst du aus? + Du erstellst eine eigene Webseite oder einen Blog und schreibst (erste) Texte dafür.

Das Kommunikationskonzept sollte beinhalten:

## Analyse
- Bewertung der Ausgangssituation und Ableitung von konkreten Aufgaben für die Kommunikation
- Systematic analysis of the initial conditions; 

## Planung (Kernelemente: Ziele, Strategien und Maßnahmen)

- statische Seite gebaut basierend auf existierenden Informationen
- Vernetzung der Informationen: Personen, Projekte, Publikationen, Software, 
- Brainstorming of target audiences
- Brainstorming/Feedback on issues; things that work and don't work

## Umsetzung (Gestaltung von Maßnahmen durch Text, Bild und Aktionen)

- Umsetzung mit Visual Studio Code & Claude Code
- Update der ursprünglichen Jekyll Seite durch modernes framework unterstützt
- Managing changes in github


## Kontrolle (Steuerung der Zielerreichung und Erfolgskontrolle)
- [ ] Collected feedback from stackholders;
